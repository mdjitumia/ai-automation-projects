# Competitor Price Watchdog

An n8n Cloud-based AI automation system for automated competitor price monitoring, comparison, AI interpretation, and Telegram reporting.

## Workflows

- **Monitor & Alert** - checks tracked competitor product prices daily, detects changes, updates Google Sheets, and sends an AI-assisted Telegram alert when a change is detected.
- **Daily Summary** - generates a concise daily pricing summary from the latest Google Sheets state and sends it to Telegram.

## Stack

**n8n Cloud • Apify • Google Sheets • Gemini • Telegram • JavaScript**

See [`documentation.md`](documentation.md) for the architecture, workflow logic, validation, and setup  notes.
